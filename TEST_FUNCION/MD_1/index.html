PAGE 02 / 规律

我看着那份收集了 127 份样本的报告，

试图用最理性的数据，去解构我们这三年。


原来，42.5% 的青春，都会输给“圈子不同”。

原来，46.5% 的旧友，最终都会走向“随缘”。

原来，无论是异性还是同性，都有 22% 的概率，最终变成“熟悉的陌生人”。

“你没有选错，你只是刚好和我，一起走进了那 22% 的规律里。这不是背叛，这只是青春的自然代谢。”

我曾不甘心，想用这份冰冷的报告去质问你，讨要一个说法。

PAGE 03 / 和解

但我现在释怀了。


既然那份问卷已经是我们的终局，

那就不去打扰了。


不用冰冷的数据去覆盖曾经真挚的三年，

不让你看到我深夜内耗的偏执，

是我能给你，也能给我自己，最后的温柔。


真正的告别，不需要大张旗鼓。
