最大似然估计 (MLE) 与最大后验估计 (MAP)
从零开始的完整数学推导

本文从 一次抛硬币 出发，逐步推导出最大似然估计（MLE）和最大后验估计（MAP）的完整数学公式。 全程只用到 乘法原理、加法原理、组合数、对数、求导 等高中知识，每一行代数变形都配有详细说明。

第一部分 · 从零开始：组合数 \(C_{10}^{8}\) 的由来

我们抛一枚硬币 10 次，记正面朝上的概率为 \(\theta\)。问：恰好出现 8 次正面 的概率是多少？

1.1 某一种特定顺序的概率

先规定一个 极其严格的顺序，比如「前 8 次正面，后 2 次反面」：

\[ P(\text{正正正正正正正正 反反}) = \underbrace{\theta \times \cdots \times \theta}_{8\text{个}} \times \underbrace{(1-\theta) \times \cdots \times (1-\theta)}_{2\text{个}} = \theta^{8} (1-\theta)^{2} \]
【这一步在干什么？】 乘法原理：10 次独立抛掷同时发生的概率，等于每次概率的乘积。 8 个 \(\theta\) 相乘得 \(\theta^8\)，2 个 \((1-\theta)\) 相乘得 \((1-\theta)^2\)。

1.2 有多少种这样的顺序？—— 组合数

题目只说「10 次里有 8 次正面」，并没有规定 这 8 次正面必须在前 8 次。这 8 次正面可以分布在 10 个位置中的任意 8 个位置上。

\[ \text{选法数} = C_{10}^{8} = \frac{10!}{8! \cdot (10-8)!} = \frac{10!}{8! \cdot 2!} = 45 \]
【为什么乘以组合数？】 这 45 种情况是 互斥 的（你不可能同时既是「1~8 次为正」又是「2~9 次为正」）。 根据 加法原理，总概率 = 45 个相同概率相加 = \(45 \times \theta^8(1-\theta)^2\)。
📖 原始概率公式（似然函数）
\[ \boxed{L(\theta) = C_{10}^{8} \cdot \theta^{8} \cdot (1-\theta)^{2}} \]

其中 \(C_{10}^{8}=45\) 是组合常数，不影响求最大值的位置，后续推导中会合法地忽略它。

第二部分 · 最大似然估计 (MLE) 全程推导

核心理念 找一个 \(\theta\)，使得 「观测到 10 次中 8 次正面」这一事件的概率最大。

2.1 写出似然函数（丢掉常数）

由于常数 \(C_{10}^{8}=45\) 在求导解方程时会被消掉（见下方证明），我们直接使用简化形式：

\[ L(\theta) = \theta^{8} (1-\theta)^{2} \]
【为什么可以丢掉 45？】 设 \(L(\theta)=45 \cdot f(\theta)\)，则 \(L'(\theta)=45 \cdot f'(\theta)\)。 令 \(L'(\theta)=0\)，两边同除以 45 得 \(f'(\theta)=0\)。最大值点完全相同，故常数可忽略。

2.2 取对数（化乘为加）

对 \(L(\theta)\) 取自然对数，记 \(\ell(\theta)=\ln L(\theta)\)：

\[ \ell(\theta) = \ln\left[\theta^{8}(1-\theta)^{2}\right] = \ln(\theta^{8}) + \ln((1-\theta)^{2}) = 8\ln\theta + 2\ln(1-\theta) \]
【为什么要取对数？】 ① 对数函数 \(\ln\) 是单调递增的，\(L(\theta)\) 的最大值点和 \(\ln L(\theta)\) 的最大值点完全一致。 ② 取对数后，乘法变加法，指数变系数，求导变得非常简单。

2.3 对 \(\theta\) 求导

对 \(\ell(\theta)\) 关于 \(\theta\) 求导（注意链式法则）：

\[ \ell'(\theta) = \frac{d}{d\theta}\big[8\ln\theta\big] + \frac{d}{d\theta}\big[2\ln(1-\theta)\big] = \frac{8}{\theta} - \frac{2}{1-\theta} \]
【求导细节】 ① \((8\ln\theta)' = 8 \cdot \frac{1}{\theta} = \frac{8}{\theta}\)。
② \((2\ln(1-\theta))' = 2 \cdot \frac{1}{1-\theta} \cdot (-1) = -\frac{2}{1-\theta}\)（链式法则）。

2.4 令导数为 0，解方程

\[ \frac{8}{\theta} - \frac{2}{1-\theta} = 0 \quad\Longrightarrow\quad \frac{8}{\theta} = \frac{2}{1-\theta} \]

交叉相乘：

\[ 8(1-\theta) = 2\theta \quad\Longrightarrow\quad 8 - 8\theta = 2\theta \quad\Longrightarrow\quad 8 = 10\theta \quad\Longrightarrow\quad \theta = \frac{8}{10} = 0.8 \]
【解方程思路】 移项 → 交叉相乘 → 合并同类项 → 系数化为 1。

2.5 验证最大值（二阶导数）

\[ \ell''(\theta) = -\frac{8}{\theta^2} - \frac{2}{(1-\theta)^2} < 0 \]

因为 \(\theta^2>0\) 且 \((1-\theta)^2>0\)，所以 \(\ell''(\theta)<0\) 恒成立，\(\theta=0.8\) 是 最大值点。

✅ MLE 最终结论
\[ \boxed{\hat{\theta}_{MLE} = \frac{8}{10} = 0.8} \]

最大似然估计认为：这枚硬币正面朝上的概率是 0.8（即 8/10）。

第三部分 · 最大后验估计 (MAP) 全程推导

核心理念 在 MLE 的基础上，乘以一个 先验信念 \(P(\theta)\)。 假设我们事先认为「大多数硬币是公平的」，用 \(P(\theta)=\theta(1-\theta)\) 来表达这种信念（该函数在 \(\theta=0.5\) 时取最大值）。

3.1 构造 MAP 目标函数（似然 × 先验）

\[ \text{目标} = L(\theta) \times P(\theta) = \big[\theta^{8}(1-\theta)^{2}\big] \times \big[\theta(1-\theta)\big] \]

合并同底数幂（指数相加）：

\[ \text{目标} = \theta^{8+1} \cdot (1-\theta)^{2+1} = \theta^{9} (1-\theta)^{3} \]
【先验怎么变成指数的？】 \(P(\theta)=\theta(1-\theta)\) 给 \(\theta\) 的指数加了 1，给 \((1-\theta)\) 的指数加了 1。 所以原来 8 变成 9，2 变成 3。

3.2 取对数

\[ \ell_{MAP}(\theta) = \ln\left[\theta^{9}(1-\theta)^{3}\right] = 9\ln\theta + 3\ln(1-\theta) \]

3.3 对 \(\theta\) 求导

\[ \ell_{MAP}'(\theta) = \frac{9}{\theta} - \frac{3}{1-\theta} \]

3.4 令导数为 0，解方程

\[ \frac{9}{\theta} - \frac{3}{1-\theta} = 0 \quad\Longrightarrow\quad \frac{9}{\theta} = \frac{3}{1-\theta} \]

交叉相乘：

\[ 9(1-\theta) = 3\theta \quad\Longrightarrow\quad 9 - 9\theta = 3\theta \quad\Longrightarrow\quad 9 = 12\theta \quad\Longrightarrow\quad \theta = \frac{9}{12} = 0.75 \]

3.5 验证最大值

\[ \ell_{MAP}''(\theta) = -\frac{9}{\theta^2} - \frac{3}{(1-\theta)^2} < 0 \]
✅ MAP 最终结论
\[ \boxed{\hat{\theta}_{MAP} = \frac{9}{12} = 0.75} \]

最大后验估计认为：考虑了「硬币大多公平」的先验后，正面概率被拉向 0.5，估计值为 0.75。

第四部分 · MLE 与 MAP 的核心对比

📊 最大似然估计 (MLE)

\[ \hat{\theta}_{MLE} = \arg\max_{\theta} P(\text{数据}|\theta) \]

只看数据，没有任何先验信念。

本例结果：\(\hat{\theta}_{MLE} = \dfrac{8}{10} = 0.8\)

📊 最大后验估计 (MAP)

\[ \hat{\theta}_{MAP} = \arg\max_{\theta} P(\text{数据}|\theta) \cdot P(\theta) \]

数据 + 先验，先验 \(P(\theta)=\theta(1-\theta)\)。

本例结果：\(\hat{\theta}_{MAP} = \dfrac{9}{12} = 0.75\)

4.1 公式对比（并排看）

方法 目标函数（取对数前） 目标函数（取对数后） 解出的 \(\theta\)
MLE \(\theta^{8}(1-\theta)^{2}\) \(8\ln\theta + 2\ln(1-\theta)\) \(\dfrac{8}{10}=0.8\)
MAP \(\theta^{9}(1-\theta)^{3}\) \(9\ln\theta + 3\ln(1-\theta)\) \(\dfrac{9}{12}=0.75\)
【规律发现】 MAP 仅仅是在 MLE 的指数上 各加了一个 1（来自先验 \(\theta(1-\theta)\)）， 所以结果从 \(\frac{8}{10}\) 变成了 \(\frac{9}{12}\)。先验相当于 「虚拟数据」——提前看到了 1 次正面和 1 次反面。

第五部分 · 通用框架：\(n\) 个独立观测值

现在把问题推广到 任意 \(n\) 次独立试验，观测值为 \(x_1, x_2, \dots, x_n\)。

5.1 通用似然函数

\[ L(\theta) = \prod_{i=1}^{n} P(x_i \mid \theta) \]
【含义】 连乘符号 \(\prod\) 表示把 \(n\) 个独立事件的概率乘在一起。 因为每次试验独立，所以联合概率等于各自概率的乘积。

5.2 取对数（通用）

\[ \ell(\theta) = \ln L(\theta) = \sum_{i=1}^{n} \ln P(x_i \mid \theta) \]
【含义】 连乘变成连加（\(\sum\)），这是对数的核心威力。

5.3 MLE 通用极值方程

\[ \boxed{\sum_{i=1}^{n} \frac{d}{d\theta} \ln P(x_i \mid \theta) = 0} \]

解这个方程，得到的 \(\theta\) 就是最大似然估计值。

5.4 MAP 通用极值方程

\[ \boxed{\sum_{i=1}^{n} \frac{d}{d\theta} \ln P(x_i \mid \theta) + \frac{d}{d\theta} \ln P(\theta) = 0} \]
【对比】 MAP 的方程比 MLE 多了一项 \(\frac{d}{d\theta}\ln P(\theta)\)， 这就是「先验」对估计值的 拉扯效应。

第六部分 · 验证：把通用公式套回抛硬币

抛 \(n\) 次硬币，正面出现 \(k\) 次。单个数据点 \(x_i \in \{1,0\}\) 的概率为：

\[ P(x_i \mid \theta) = \theta^{x_i} (1-\theta)^{1-x_i} \]

（当 \(x_i=1\) 时为 \(\theta\)，当 \(x_i=0\) 时为 \(1-\theta\)，完美统一。）

6.1 代入 MLE 通用公式

取对数：\(\ln P(x_i \mid \theta) = x_i \ln\theta + (1-x_i)\ln(1-\theta)\)

代入 \(\sum_{i=1}^{n} \frac{d}{d\theta}\ln P = 0\)：

\[ \sum_{i=1}^{n} \left( \frac{x_i}{\theta} - \frac{1-x_i}{1-\theta} \right) = 0 \]

因为 \(\sum x_i = k\)，\(\sum (1-x_i) = n-k\)：

\[ \frac{k}{\theta} - \frac{n-k}{1-\theta} = 0 \quad\Longrightarrow\quad k(1-\theta) = (n-k)\theta \quad\Longrightarrow\quad \theta = \frac{k}{n} \]
✅ 完美吻合！ MLE 的结果就是 频率 \(k/n\)。

6.2 代入 MAP 通用公式（先验 \(P(\theta)=\theta(1-\theta)\)）

先验对数：\(\ln P(\theta)=\ln\theta+\ln(1-\theta)\)，导数为 \(\frac{1}{\theta} - \frac{1}{1-\theta}\)

代入 MAP 通式：

\[ \left( \frac{k}{\theta} - \frac{n-k}{1-\theta} \right) + \left( \frac{1}{\theta} - \frac{1}{1-\theta} \right) = 0 \]

合并同类项：

\[ \frac{k+1}{\theta} - \frac{n-k+1}{1-\theta} = 0 \quad\Longrightarrow\quad (k+1)(1-\theta) = (n-k+1)\theta \quad\Longrightarrow\quad \theta = \frac{k+1}{n+2} \]
✅ 完美吻合！ 对于 \(n=10, k=8\)，得 \(\frac{9}{12}=0.75\)。 先验给分子加了 1，分母加了 2（1 正 1 反）。

第七部分 · 终极总结（贴在笔记本扉页）

📖 两大核心公式
方法 目标函数（取对数后） 极值方程（令导数为 0）
MLE \(\displaystyle \ell(\theta) = \sum_{i=1}^{n} \ln P(x_i \mid \theta)\) \(\displaystyle \sum_{i=1}^{n} \frac{d}{d\theta} \ln P(x_i \mid \theta) = 0\)
MAP \(\displaystyle \ell_{MAP}(\theta) = \sum_{i=1}^{n} \ln P(x_i \mid \theta) + \ln P(\theta)\) \(\displaystyle \sum_{i=1}^{n} \frac{d}{d\theta} \ln P(x_i \mid \theta) + \frac{d}{d\theta} \ln P(\theta) = 0\)
🎯 操作口诀：
遇见数据多，先写似然乘积；
取对数变求和，求导令零解方程。
MLE 解数据，MAP 多加个先验导。

📌 什么场景用什么？

  • 有大量可靠数据 → 用 MLE（简单直接，数据会淹没先验）。
  • 数据很少 或 先验非常强（如物理定律） → 用 MAP（更稳健）。
  • 数据量极大时，MLE 和 MAP 结果 趋同（先验被稀释）。

第八部分 · 多个事件（A、B、C 三类结果）

当一次试验有 3 种互斥结果（如抽奖分红、黄、蓝），记为 A、B、C，对应概率 \(\theta_A, \theta_B, \theta_C\)，且 \(\theta_A+\theta_B+\theta_C=1\)。

重复 \(N\) 次，观察到 \(n_A, n_B, n_C\) 次，\(n_A+n_B+n_C=N\)。

8.1 MLE 结果

\[ \hat{\theta}_A^{MLE} = \frac{n_A}{N},\quad \hat{\theta}_B^{MLE} = \frac{n_B}{N},\quad \hat{\theta}_C^{MLE} = \frac{n_C}{N} \]
推导思路： 似然函数为 \(\theta_A^{n_A}\theta_B^{n_B}\theta_C^{n_C}\)， 在约束 \(\theta_A+\theta_B+\theta_C=1\) 下求偏导，得到频率比例。

8.2 MAP 结果（先验 \(\theta_A\theta_B\theta_C\)）

\[ \hat{\theta}_A^{MAP} = \frac{n_A+1}{N+3},\quad \hat{\theta}_B^{MAP} = \frac{n_B+1}{N+3},\quad \hat{\theta}_C^{MAP} = \frac{n_C+1}{N+3} \]
【规律】 每个类别的分子加 1，分母加 3（共 3 个类别）。 这就是「虚拟数据」——提前看到 A、B、C 各一次。
